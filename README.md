## Descripción

Repositorio de un proyecto académico de **Estructuras de Datos**, desarrollado en el contexto de Ingeniería en Computación.

El proyecto aborda la aplicación de estructuras de datos no lineales, particularmente **grafos y árboles**, utilizando un contexto relacionado con aeropuertos.

Su propósito académico es fortalecer la implementación de estructuras de datos, la organización del código y la resolución de problemas mediante programación.

## Objetivos

- Aplicar conceptos de estructuras de datos no lineales.
- Comprender la representación y organización de relaciones mediante grafos.
- Estudiar el uso de árboles para organizar y consultar información.
- Reforzar conceptos de programación orientada a objetos.
- Desarrollar habilidades de análisis, implementación y depuración de software.

## Funcionalidades y conceptos abordados

### 1. Grafos

Los grafos permiten representar relaciones entre entidades mediante vértices y aristas.

En un contexto aeroportuario, pueden utilizarse para modelar aeropuertos y las conexiones existentes entre ellos.

### 2. Árboles

Los árboles permiten organizar información mediante relaciones jerárquicas.

Su estudio comprende conceptos como nodos, raíz, niveles, hojas y recorridos.

### 3. Organización del código

El proyecto constituye una oportunidad para aplicar separación de responsabilidades, reutilización de código y modelado de entidades mediante programación orientada a objetos.

> **Nota:** Esta sección describe el enfoque académico. Debe completarse con las operaciones y los algoritmos efectivamente presentes en la implementación.

## Instalación y ejecución

### Requisitos

- Java Development Kit (JDK), en la versión compatible con el proyecto.
- Un IDE compatible con Java, como IntelliJ IDEA.
- Git, opcional para clonar el repositorio.

### Paso 1. Clonar el repositorio

```bash
git clone https://github.com/Sam-ai06/Grafos-Arboles-Aeropuerto.git
```

### Paso 2. Acceder al directorio

```bash
cd Grafos-Arboles-Aeropuerto
```

### Paso 3. Abrir el proyecto

1. Inicia IntelliJ IDEA.
2. Selecciona **File → Open**.
3. Abre el directorio del módulo que deseas explorar.
4. Configura el JDK compatible.
5. Espera a que se carguen las dependencias y la configuración del proyecto.

### Paso 4. Ejecutar la aplicación

Identifica la clase principal o la configuración de ejecución del módulo seleccionado.

En caso de disponer de una clase con el método `main`, ejecútala desde el IDE.

> La clase de entrada, las dependencias y la versión exacta de Java están pendientes de verificar.

## Guía de usabilidad

### ¿Cómo explorar el proyecto?

**1. Selecciona un módulo**

Examina las carpetas `ED_P3_grupo1` y `proyecto estructuras de datos` para identificar sus componentes y archivos fuente.

**2. Identifica las estructuras de datos**

Revisa las clases relacionadas con grafos, árboles y entidades del dominio aeroportuario.

**3. Localiza el punto de entrada**

Busca la clase responsable de iniciar la aplicación y revisa las opciones o funcionalidades que ofrece.

**4. Ejecuta las operaciones disponibles**

Utiliza los mecanismos de interacción definidos en el módulo: interfaz gráfica, consola u otro punto de entrada, según corresponda.

**5. Analiza los resultados**

Observa cómo las estructuras de datos permiten representar, organizar o procesar la información utilizada por la aplicación.
